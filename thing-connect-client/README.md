# ThingConnect Taro 微信小程序

本目录使用 Taro、React 和 TypeScript 开发独立微信小程序，保留后续跨平台扩展的工程结构。当前开发与验收目标是微信小程序。
它与 `thing-connect/` 平级，独立安装、构建和导入微信开发者工具，不覆盖旧 Web 或旧小程序。

## 当前范围

- 邮箱登录、注册、找回密码与易盾微信验证插件。
- 设备列表、下拉刷新、设备绑定、改名、解绑和分场景媒体信息。
- 原生联系人页面：搜索、分类、申请、审批、备注和删除。
- 账号信息、退出登录和原生协议阅读。
- 微信设备授权、插件通话入口及双向画面配置。

- AI 角色列表、创建、基础配置编辑、切换和删除。编辑已有角色时保留未编辑的服务、知识库和工具配置；知识库、MCP、设备插件的管理界面仍需在现有 Web 使用。
- AI 识别类型选择、排序、开关、额度展示和版本冲突提示。
- 设备多人对讲房间创建、加入、退出和手动刷新。
- AI 对话记录分页、详情阅读和删除。

登录、注册与找回密码采用紧凑表单。成功登录后在本机记住邮箱，下次进入登录页自动填入；退出登录仍保留邮箱，不保存密码。“设备”和“我的”使用底部导航。设备卡片直接进入 AI 角色、AI 识别和联系人；多人对讲、AI 对话记录、微信通话授权及设备管理位于设备“⋯”菜单。未授权时，通话主按钮用于授权，授权完成后再点击发起通话。

H5 构建入口仅为后续扩展保留，不作为当前交付端，不涉及现有 Web 的替换或部署。

## 开发

要求 Node.js 22.12 或更高版本、npm 10 或更高版本。

```bash
cd thing-connect-client
npm ci
npm run check
npm run dev:weapp
```

在微信开发者工具中导入 **`thing-connect-client/`**，`project.config.json` 指向 `dist/weapp/`。
该项目需要具有微信 IoT VoIP 与易盾插件使用权限的正式 AppID。合法 request 域名和播放器 web-view 业务域名需在微信后台配置。

构建命令：

```bash
npm run build:weapp
npm run build:h5
```

产物分别位于 `dist/weapp/` 和 `dist/h5/`。构建不会写入 `thing-connect/user-server/static/`，也不会替换 `thing-connect/weixin-mini-program/`。

服务地址通过构建环境变量配置：

| 变量 | 用途 |
|---|---|
| `TARO_APP_API_ORIGIN` | 小程序默认 `https://xiaotai.chat`；H5 默认使用同源 `/v1/`，由部署代理转发 |
| `TARO_APP_WX_MODEL_ID` | 微信 IoT 型号 ID，与设备和微信后台配置保持一致 |

`project.config.json` 中的 AppID 需与微信后台开通的插件和 VoIP 能力匹配。AppID、ModelID 是公开标识，用户 JWT 只在运行时保存，不放入源码或构建环境变量。

H5 本地静态服务器只用于页面预览；接口联调需要将 `/v1/` 代理到业务服务。显式指定跨域 API 地址时，服务端须允许对应来源，不能通过关闭浏览器安全设置解决。

## 播放、授权与通话

三种操作的入口、能力与权限独立处理：

| 操作 | 设备能力 | 微信端实现 |
|---|---|---|
| 实时查看 | `profiles.stream` | 固定播放器 web-view，复用现有 TiRTC Web SDK；这部分不是原生媒体播放器 |
| 通话授权 | 微信授权状态与服务端授权关系 | 微信原生授权 API；用户仍需确认微信弹窗 |
| 微信通话 | `profiles.voip` | 微信 `wmpf-voip` 插件 |

播放不要求微信通话授权。授权状态未知时先查询，未授权时请求授权，已关闭时引导微信设置。微信通话依据 `voip` 中设备摄像头和屏幕能力选择语音、单向视频或双向视频；不借用 `stream` 或 `call` 的字段。

设备列表加载完成后即可浏览和操作，微信授权状态在后台查询。按钮显示“确认通话授权”时，点击会先确认授权状态，再按通话流程继续；查询失败不表示授权被撤销。占线或无人接听时会提示原因，可稍后再次呼叫。

播放器入口先验证设备归属和在线状态，再将 JWT 放入 URL fragment，由现有播放器消费；不将 JWT 放入 query、日志或分享链接。播放器及其服务页面须与服务端协议兼容。

`platform/media.weapp.ts` 和 `platform/captcha.weapp.tsx` 隔离微信能力。共享页面不能直接调用微信插件，也不能将浏览器 DOM API 带入小程序。

`prepare:assets` 只读旧工程中的已验证视频参数工具和法律文本，生成本目录内的构建文件。它不修改旧工程，也不要求旧工程运行；构建时需要完整仓库。生成文件不提交，修改源文件后重新构建即可同步。

## 验证边界

构建产物预算为 1.5 MiB，给微信工具加工留出余量；实际预览包大小以微信开发者工具为准。登录头像使用不超过 64 KiB 的透明 PNG 小图，完整原图不进入小程序包。构建脚本检查预算与头像内嵌。

`npm test` 检查业务错误码、联系人分类约束，以及播放、授权、通话的场景隔离。
`npm run typecheck` 检查 TypeScript；`npm run build:weapp` 检查微信编译产物。

开发者工具联调应覆盖登录、列表加载与返回、联系人表单、网络失败和 JWT 过期。页面返回或切回前台不会自动刷新设备列表，绑定成功等显式修改会更新相关数据；设备列表通过下拉刷新获取最新状态；其他功能页使用各自的刷新入口。

真机必须分别验证易盾弹窗、微信授权拒绝及恢复、纯音频通话、单向和双向视频、设备来电、取消及挂断、画面旋转镜像、播放器权限和弱网恢复。编译成功或模拟器页面正常不等于这些链路通过。
