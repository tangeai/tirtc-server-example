Windows 10/11 x64 · PowerShell；先安装 Git 与 Python 3.14，安装后重新打开终端。

1. 准备环境 
winget install -e --id Git.Git
winget install -e --id Python.Python.3.14
2. 下载并启动 
git clone https://github.com/tangeai/tirtc-server-example.git
cd tirtc-server-example/thing-connect/device-sim/device-sim-py
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe device_sim_main.py
完整指南与故障排查 ↗

Ubuntu x64 · CPython 3.10–3.14

1. 准备环境 
sudo apt update
sudo apt install -y git python3 python3-venv
2. 下载并启动 
git clone https://github.com/tangeai/tirtc-server-example.git
cd tirtc-server-example/thing-connect/device-sim/device-sim-py
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python device_sim_main.py

Ubuntu x64 · Linux C 文件媒体示例

1. 准备环境 
sudo apt update
sudo apt install -y git build-essential pkg-config libcurl4-openssl-dev libssl-dev libmosquitto-dev libcjson-dev
2. 下载并启动 
git clone https://github.com/tangeai/tirtc-server-example.git
cd tirtc-server-example/thing-connect/device-sim/device-sim-c
make WERROR=1
./device-sim --mac AA:BB:CC:DD:EE:FF
