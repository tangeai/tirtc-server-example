# Admin 前端一致性

新增页面、功能入口或修改查询、列表、弹窗时，先阅读 `src/shared/admin-ui.tsx`，再对照相邻页面选择现有模式。用户操作语义见 `../admin-server/README.md` 的“列表查询与操作”。本目录使用下列统一规则。

## 组件与布局

- 页面标题使用 `pageTitle`；整页操作放在页头右侧，独立分区的操作放在分区标题右侧。
- 业务操作使用 Ant Design `Button`，同时提供语义相符的 `icon` 和可见中文文案。动态动作的图标与文案同步切换。组件库内置的关闭、折叠、清空、分页箭头等辅助控件保持原生交互。
- 新增、保存、发布等主要操作使用主按钮；表格行操作使用链接按钮，破坏性操作标为 `danger`。行操作允许换行，不能遮住数据列。
- 刷新复用 `RefreshButton`，传入覆盖其全部请求的加载状态；查询表单使用 `QueryFilter` 和 `queryActions(loading)`；确认浮层复用 `confirmationActions`，表单型弹窗的保存、取消按钮也配置图标。
- 时间使用 `formatTime`，服务状态复用共享状态展示。分页列表默认每页 20 条，显示结果总数；本地完整列表复用 `localPagination`，服务端分页绑定当前页和服务端总数。

## 查询与数据

- 区分输入中的条件与已提交条件，点击“查询”或回车才应用；提交相同条件仍应重新查询。查询、重置回到第一页，刷新保留已提交条件、排序及页码。
- 每个页面或查询分区独立持有筛选状态；共用页面组件切换业务类型时重置状态。跨请求结果采用代次校验，旧请求不得覆盖新结果。
- 筛选字段必须与接口实际能力一致；服务端分页列表不能仅过滤当前页。全量目录的本地筛选和接口的最近 N 条上限应在界面明确表达。
- 查询区复用 `useCompactQueryLayout`，按字段内容选择状态、编号、文本、日期等宽度；空间足够时条件与按钮同排，窄屏自然换行。数字与普通单选控件使用适量宽度，长文本、密钥和多选保留阅读与输入空间。
- 查询字段提供中文标签、输入提示和适当类型；编号使用数字控件，状态使用枚举，下拉搜索按展示名称匹配。
- 保留加载、无匹配结果和失败反馈的区别；失败后能够重试。操作后的刷新沿用当前查询语境。

## 完成标准

- 运行本目录 `package.json` 的 `check`。其中 `check:ui` 检查按钮结构、刷新复用和查询操作区；新模式需要调整检查器时，同步增加能证明合法用法通过、违规用法失败的用例。
- 查询或列表交互变化，用模拟接口验证重复查询、重置、翻页后刷新、失败恢复及页面切换；带数据检查桌面和窄屏的列内容、操作区与弹窗。静态检查不代替这些验收。
